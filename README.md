# E-Book App — MAD Assignment 3

This is an E-Book mobile application developed using React Native and Expo.

## Getting Started

### 1. Install Dependencies

```bash
npm install
```

### 2. Start the Application

```bash
npx expo start
```

### 3. Run on Android

```bash
npx expo start --android
```

## Technologies Used

* React Native
* Expo SDK 57
* TypeScript
* Expo Router

## Project Structure

The project contains application source code, reusable components, assets, and configuration files.
